# Airoha MIPS DRAM Calibration - opensource

This repository containing the files required for calibrating Airoha (formerly Econet) MIPS SoCs and a simple `flash reader` to load u-boot or another bootloader and simples chainload for recovery.

##  SoC

- en751221
- en751627 (WIP)
- en7528
- en7580 (WIP)
